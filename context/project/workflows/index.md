# Operator workflows

Our release engineering and instance operations live here. Reusable fleet passes live in `blizzard-usage`; the table
routes directly to their shared owners. Every fleet call uses [our binding](../blizzard-binding.md). Feature delivery
and engineering procedures belong to `blizzard-context:/workflows/index.md`. Parent hub: [../index.md](../index.md).

| File                                                                          | When to read                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [release.md](./release.md)                                                    | Cutting a release — tagging a candidate at its cut commit, or promoting it to the stable tag — from a proven-green commit to a published wheel and image                                                          |
| [release-deploy.md](./release-deploy.md)                                      | Moving our dogfood instance onto a published release, or back off one                                                                                                                                             |
| [release-train.md](./release-train.md)                                        | Told to run the release train, cut a minor, or promote a baked candidate — promoting the waiting candidate or setting it aside, cutting the next minor's candidate and its branch, or cutting a further candidate |
| [release-patch.md](./release-patch.md)                                        | Told to patch a release line, or a fix that cannot wait for the train must reach a line already released                                                                                                          |
| [release-major.md](./release-major.md)                                        | A major's published date is four trains away or nearer — opening `master` for it, cutting its candidates, closing `master`, and promoting it or slipping the date                                                 |
| [feeding-the-dog.md](./feeding-the-dog.md)                                    | Told to run feeding-the-dog, or to move the instance onto a `master` commit rather than a release                                                                                                                 |
| [findings-sweep.md](./findings-sweep.md)                                      | Running the findings sweep — the recurring operator pass that re-verifies the hub's live findings and drafts them into proposals or withdrawals                                                                   |
| [Proposal review](blizzard-usage:/context/workflows/proposal-review.md)       | Reviewing or deciding garden proposals                                                                                                                                                                            |
| [Tending the garden](blizzard-usage:/context/workflows/tending-the-garden.md) | Choosing and starting routine sweeps                                                                                                                                                                              |
| [Marshalling](blizzard-usage:/context/workflows/marshalling.md)               | Marshalling the backlog or preparing newly minted chunks                                                                                                                                                          |
| [store-fold.md](./store-fold.md)                                              | Told to fold the store trees, or when a train is due a baseline — replacing the migration history up to the oldest supported release with one revision each                                                       |
